# Project Zomboid Mod Menu — feature reference

Use the Project Zomboid mod menu workspace to move between module groups, character profiles, and world settings. The section map below gives each part a clear place in the project.

| Section | Description |
|---|---|
| Module groups | Content and resource groups, together with their configuration or organization details. |
| Character profiles | Related settings collected into named groups for a clearer configuration workflow. |
| World settings | A dedicated section for world settings and the configuration details associated with that area. |

The project page follows the same section structure.
